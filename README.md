Day 1 TIK Mengajar - Workshop Mempelajari Git &amp; Github

Nama Lengkap : Khairuman Faza

Tujuan & Kegunaan Repository :Repository (atau sering disingkat repo) adalah tempat penyimpanan digital terpusat yang digunakan untuk menyimpan, mengelola, dan mengorganisasi berbagai berkas, kode sumber (source code), beserta dokumentasi suatu proyek. Tujuan utama dari pembuatan repository adalah untuk menyediakan satu pusat kendali yang terstruktur dan aman, sehingga seluruh aset proyek dapat diakses, dipantau, dan dikembangkan secara efisien tanpa tercecer di berbagai perangkat yang berbeda.

Dari segi kegunaan, fungsi paling krusial dari sebuah repository adalah mendukung sistem kontrol versi (version control system). Melalui fitur ini, setiap perubahan, penambahan, atau penghapusan file dapat dicatat secara rinci beserta riwayat waktunya, memungkinkan pengembang untuk melihat siapa yang melakukan revisi dan dengan mudah mengembalikan (rollback) kode ke versi stabil sebelumnya jika terjadi kesalahan. Selain itu, repository menjadi sarana kolaborasi utama bagi tim, di mana banyak orang dapat bekerja pada proyek yang sama secara bersamaan melalui fitur branching (pencabangan) dan merging (penggabungan) tanpa khawatir pekerjaan mereka saling menimpa.

Kegunaan lainnya yang tidak kalah penting adalah sebagai media pencadangan (backup) berbasis cloud yang aman—seperti melalui platform GitHub, GitLab, atau Bitbucket—sehingga data proyek tetap terlindungi meskipun perangkat lokal mengalami kerusakan atau kehilangan. Di luar dunia pemrograman, repository juga sering dimanfaatkan sebagai arsip digital institusi atau perpustakaan akademik untuk menyimpan jurnal, laporan penelitian, serta data penting agar mudah ditemukan kembali dan dibagikan secara luas.

Rangkuman Materi yang Disampaikan Selama Workshop
Pengantar Prompt Engineering: Peserta mempelajari cara merancang instruksi (prompt) yang spesifik agar model AI dapat memberikan jawaban yang tepat, relevan, dan layak digunakan. Struktur prompt yang baik harus mencakup komponen Role (Peran), Task (Tugas), Context (Konteks), dan Format (Format keluaran).   
Pengenalan Git & GitHub: Memahami perbedaan mendasar antara Git (sistem version control terdistribusi untuk melacak perubahan kode secara lokal) dan GitHub (platform berbasis web untuk menyimpan repository secara online dan mendukung kolaborasi tim).   
Git Workflow & Perintah Esensial: Mempelajari alur kerja Git yang melibatkan Working Directory, Staging Area, dan .git directory (Repository). Peserta juga diajarkan perintah dasar seperti git init, git add, git commit, git push, dan git pull.
Setup Lingkungan Pengembangan: Melakukan instalasi Git, pengaturan identitas global (user name dan email), konfigurasi VS Code, serta pembuatan dan pendaftaran kunci SSH (SSH Key) berbasis Ed25519 untuk autentikasi aman ke GitHub.   
Proyek Praktik (Student Task Planner): Sesi ditutup dengan praktik langsung merancang aplikasi web sederhana perencana tugas pelajar menggunakan bantuan AI, lalu menginisiasinya ke dalam Git dan mengunggahnya ke GitHub.   

Poin-Poin Penting atau Pengetahuan Baru yang Dipelajari
Pemberian konteks dan struktur prompt yang jelas (Role, Task, Context, Format) sangat menentukan kualitas dan akurasi hasil keluaran dari AI.   
Keuntungan utama dari prompt engineering meliputi peningkatan performa model AI, pengurangan bias/respon ofensif, peningkatan kontrol, serta pengalaman pengguna yang lebih baik.   
Git diciptakan oleh Linus Torvalds pada tahun 2005 untuk mencatat setiap perubahan, siapa yang mengubah, dan kapan perubahan itu terjadi pada suatu berkas.   
Staging area (atau index) berfungsi sebagai area penampungan sementara yang menyimpan informasi perubahan sebelum dimasukkan ke dalam commit berikutnya.   
Penggunaan kunci SSH (SSH Key) dengan algoritma Ed25519 memberikan tingkat keamanan tinggi dan performa optimal saat menghubungkan perangkat lokal dengan GitHub.
